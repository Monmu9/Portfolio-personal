MMCtech Tienda Gaming (proyecto único de Front-end)

PROYECTO Y CARACTERISTICAS

MMCtech es una tienda online de periféricos gaming desarrollada como proyecto académico para la asignatura de Entorno Cliente, por lo que solo incluye Front-end.
La funcionalidad principal del proyecto es la implementación de un sistema de carga dinámica de productos mediante AJAX (Fetch API), que permite mostrar productos progresivamente con un botón "Cargar más" sin necesidad de recargar la página completa.
El proyecto incluye filtros por categoría, animaciones suaves, feedback visual constante al usuario, y un diseño completamente responsive adaptado a móvil, tablet y desktop.
Está construido con HTML5 semántico, CSS3 moderno (Grid, Flexbox, Variables CSS) y JavaScript ES6+ (async/await, funciones modulares), utilizando datos en formato JSON que simulan la respuesta de una API real.

MONBANK, Banca Simulada (proyecto en desarrollo)

PROYECTO Y CARACTERISTICAS

MONBANK es una simulación bancaria desarrollada con un frontend estático que incorpora persistencia de datos mediante un archivo JSON. La interfaz es completamente responsiva y se apoya en Chart.js para la visualización dinámica de gráficos, ofreciendo una experiencia de usuario moderna y fluida.
El sistema incluye autenticación simulada en el cliente a través de localStorage, permitiendo sesiones locales sin necesidad de backend.
La gestión de movimientos financieros —crear, listar y eliminar— se realiza directamente en el archivo JSON, con filtrado por usuario y orden cronológico. La evolución del saldo se representa mediante una gráfica lineal que se actualiza automáticamente tras cada operación.
Además, cuenta con un formulario de contacto que almacena las consultas, con opciones para visualizar y eliminar mensajes.
El modo oscuro está implementado con persistencia local, mejorando la accesibilidad y personalización. Para enriquecer la experiencia, se ha incorporado un spinner de carga inicial y animaciones CSS que aportan dinamismo a la navegación.
El diseño se adapta a dispositivos móviles mediante media queries optimizadas para pantallas de hasta 600px. Se ha integrado iconografía con Font Awesome y tipografía externa desde Google Fonts, reforzando la estética visual del proyecto.

MonSnake Game

PROYECTO Y CARACTERISTICAS

Reimplementación moderna del clásico juego Snake, desarrollado desde cero utilizando el framework LibGDX.
Este proyecto demuestra habilidades en desarrollo de videojuegos multiplataforma, manejo de gráficos 2D, gestión de estados de juego y diseño de experiencia de usuario.
Características principales:
-Sistema de puntuación dual: Implementación de dos tipos de manzanas con valores diferentes (10 y 20 puntos).
-Sistema de progresión: Niveles dinámicos cada 50 puntos con cambios visuales en el entorno.
-Sistema de vidas: Gestión de tres vidas con detección de colisiones contra el propio cuerpo.
-Seguimiento de récords: HUD interactivo que detecta y celebra nuevos récords personales con efectos visuales (color dorado y parpadeo).
-Interfaz visual personalizada: Gráficos diseñados específicamente para el proyecto.
-Game Over y reinicio: Sistema completo de finalización y reinicio del juego.
